Cómo funciona

Secuencia simplificada del trabajo del lubricante dentro del engranaje.

1Los dientes trabajan con alta carga y deslizamiento.
2El aceite forma una película entre superficies.
3Los aditivos EP refuerzan la protección bajo presión.
4Se reduce el contacto metal-metal, la fricción y el desgaste.
El aceite separa superficies, soporta carga y ayuda a disipar calor.

Efecto esperado

Menor fricción entre dientes.
Menor desgaste de engranajes y cojinetes.
Menor posibilidad de rayado y picadura superficial.
Mayor vida útil del conjunto lubricado.

Interpretación SAE 80W-90

La clasificación SAE indica el comportamiento de viscosidad del lubricante.

80W
Comportamiento en frío

Indica el desempeño viscoso a baja temperatura y la facilidad de circulación en el arranque.

90
Comportamiento en caliente

Indica la viscosidad a temperatura de operación para mantener película lubricante estable.

Clave de lectura: SAE 80W-90 define viscosidad. No define por sí solo el nivel de servicio del lubricante.
6

Interpretación API GL-5

La clasificación API describe el nivel de desempeño del aceite para engranajes.

Qué indica GL-5

Servicio severo para engranajes.
Aplicación típica en engranajes hipoidales.
Protección para alta carga y alto torque.
Uso de aditivos de extrema presión (EP).

Lectura rápida

SAE = viscosidad del lubricante.

API = nivel de servicio o desempeño.

Conclusión: la selección correcta exige coincidir con el grado SAE y con la clasificación API indicada por el fabricante del equipo.

Tecnología y aditivos

Elementos funcionales que explican el comportamiento del aceite.

Aditivos EP

Refuerzan la protección bajo alta presión y carga de contacto.

Antidesgaste

Reducen deterioro de dientes, cojinetes y superficies metálicas.

Antioxidantes

Retardan la degradación del aceite durante operación y almacenamiento.

Anticorrosivos

Protegen contra herrumbre y corrosión interna.

Antiespumantes

Disminuyen la formación de espuma y aireación del lubricante.

Demulsificantes

Favorecen separación de agua y ayudan a mantener el desempeño.
